# CallRec2agent

삼성 음성녹음의 기존 전사 TXT를 Google Drive로 바로 공유하는 Android 앱입니다. 접근성 도우미가 **공유 → 텍스트 파일 → Drive → 업로드**를 처리하고, 선택한 Drive 폴더에서 새 TXT를 다시 읽어 확인한 뒤 다음 녹음으로 넘어갑니다. JSON 변환과 별도 전사 업로드 단계가 없습니다.

[APK 릴리스](https://github.com/SukbeomH/CallRec2agent/releases)

Android 13 이상, 삼성 음성녹음, Google Drive 앱과 인터넷 연결이 필요합니다. 루팅과 재전사를 하지 않습니다. 개인 기기용 디버그 서명 빌드이며 APK 업데이트는 기존 서명이 같아야 합니다.

## 처음 준비

1. **전사 Drive**를 열고 **접근성 설정 열기**에서 **전사 Drive 공유 도우미**를 직접 켭니다. Android가 제한된 설정을 표시하면 앱 정보에서 직접 허용합니다.
2. **Drive 폴더 선택·변경**에서 저장 확인에 사용할 폴더를 선택합니다. 에이전트의 Drive 연결 계정에서도 접근 가능한 전용 폴더를 사용합니다.
3. 폴더가 없으면 **하위 폴더 생성·선택**을 고르고 이름을 입력한 뒤 상위 Drive 위치를 선택합니다. 선택한 폴더가 입력한 이름과 같으면 그대로 사용합니다. 상위 폴더를 골랐다면 같은 이름의 하위 폴더를 사용하고, 없으면 생성합니다. 같은 이름의 파일이나 여러 폴더가 있으면 중지합니다.
4. 첫 TXT의 Drive 업로드 화면에서는 같은 계정·폴더를 선택하고 **업로드**를 한 번 누릅니다. 도우미가 선택한 폴더에서 새 TXT를 확인하면 이 계정을 기억합니다. 이후 같은 계정·폴더에서는 업로드 버튼도 자동으로 누릅니다. 대상이 달라지면 자동 저장하지 않습니다.

## 폰에서 사용

1. **한 건만 저장** 또는 **여러 건 순서대로 저장**을 고릅니다. 여러 건은 최대 처리 수를 정합니다.
2. **삼성 음성녹음 열기**를 누릅니다. 한 건은 전사 본문이 보이는 녹음을 열고, 여러 건은 시작할 목록 위치로 이동합니다.
3. 최근 앱에서 **전사 Drive**로 돌아와 **전송 시작**을 누릅니다. 돌아오는 것만으로 자동화가 시작되지는 않습니다.
4. 시작할 때 `llm.txt`를 같은 Drive 폴더에 자동으로 준비합니다. 삼성 앱의 TXT는 Drive로 직접 공유하며 앱 내부에 전사 사본이나 JSON을 새로 만들지 않습니다.
5. 도우미는 업로드 전 폴더의 파일 URI 목록을 기록합니다. 업로드 화면이 닫히고, 같은 이름의 **새 URI**가 선택한 폴더에 나타나며, 본문을 다시 읽어 삼성 TXT 형식을 확인한 경우만 완료로 셉니다. 기존 동명 파일을 성공 근거로 재사용하지 않습니다.
6. 완료하면 결과 화면으로 돌아옵니다. 화면 잠금을 풀어 두고 실행 중 다른 앱을 사용하지 않습니다. 앱 또는 알림의 **중지**로 멈춥니다.

삼성 원본 TXT 이름을 유지합니다. 같은 녹음을 다시 보내면 Drive에 동명 사본이 생길 수 있습니다. 마지막 파일을 확인하지 못하고 중지됐다면 재시도 전에 Drive에서 확인합니다. 파일 재읽기는 Drive 앱의 저장 상태를 확인하며 서버 동기화 완료를 보증하지 않습니다. Wi-Fi 대기 등이 있으면 Drive 앱에서 업로드를 완료해야 에이전트가 읽을 수 있습니다.

기존 버전의 로컬 JSON, Drive JSON과 `index.json`은 삭제하지 않습니다. 새 버전은 이 색인을 갱신하지 않습니다. 앱이 이전에 쓴 `llm.txt`는 내용이 수정되지 않았을 때만 갱신합니다. 사용자가 수정했거나 출처가 다른 안내문은 덮어쓰지 않고 중지합니다.

## 에이전트에 전달

> 이 Drive 폴더의 llm.txt부터 읽고 실제 TXT 목록과 본문을 확인하여 답해 주세요. 근거에는 파일 링크·발화 시작 시간·발화자 라벨을 붙여 주세요.

앱의 **에이전트 프롬프트 복사**에서 확인된 Drive 계정, 저장 위치, 저장 방식과 읽기 순서를 확인하고 **복사**합니다. **Drive 폴더 링크 설정**에 해당 폴더의 링크를 넣으면 프롬프트에 함께 포함됩니다. 계정 확인 전에는 확인되지 않았다고 표시합니다. 링크 등록 자체는 공유 권한을 변경하지 않습니다.

`llm.txt`에는 TXT 인코딩, 발화자·시간 머리글, 여러 줄 본문, 중복 사본과 기존 JSON 처리, 인용 방법을 설명합니다. 앱의 폴더 선택이 에이전트 계정의 접근 권한을 추가하지는 않습니다.

형식은 [FORMAT.md](FORMAT.md), 빌드는 [BUILD.md](BUILD.md), 내부 동작과 검증 범위는 [DESIGN.md](DESIGN.md)를 확인합니다.
