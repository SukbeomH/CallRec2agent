# CallRec2agent

삼성 음성녹음의 기존 전사를 폰에서 JSON으로 추출하고, Google Drive를 통해 에이전트가 읽을 수 있게 정리하는 Android 앱입니다.

접근성 도우미가 TXT 공유를 자동으로 처리합니다. 발화자·시작 시간·본문을 내장 저장공간에 저장하고, 선택한 Drive 폴더에 전사와 `llm.txt`, `index.json`을 함께 올립니다. 재전사와 루팅이 필요하지 않습니다.

[최신 APK 다운로드](https://github.com/SukbeomH/CallRec2agent/releases/latest)

Android 13 이상과 삼성 음성녹음 앱이 필요합니다. 추출은 인터넷 없이 동작하며, Drive 업로드에는 Google Drive 앱과 인터넷 연결이 필요합니다. 현재 배포 APK는 개인 기기 검증용 디버그 서명 빌드입니다.

## 폰에서 전사 저장하기

1. APK를 설치하고 **전사 JSON**을 엽니다. 화면 위의 **사용법**에서 전체 안내를 다시 볼 수 있습니다.
2. **준비** 화면에서 **접근성 설정 열기**를 눌러 **전사 JSON 공유 도우미**를 켭니다. Android가 설치된 앱의 접근성 사용을 제한하면 앱 정보의 **제한된 설정 허용**을 직접 처리합니다. 이미 준비된 폰은 이 단계를 건너뜁니다.
3. **선택** 화면에서 **한 건만 저장** 또는 **여러 건 순서대로 저장**을 고릅니다. 여러 건은 최대 녹음 수를 입력합니다.
4. **다음 · 녹음 준비**를 누릅니다. **삼성 음성녹음 열기**로 이동해 한 건은 전사가 보이는 녹음을 열고, 여러 건은 시작할 목록 위치로 이동합니다.
5. 최근 앱 화면에서 **전사 JSON**으로 돌아와 **추출 시작**을 누릅니다. 삼성 앱에서 돌아오는 것만으로 자동화가 시작되지는 않습니다.
6. 추출이 끝나면 **결과** 화면이 열립니다. **저장 폴더 열기**로 JSON을 찾거나 파일을 눌러 미리 봅니다. 파일 경로는 **내 파일 → 내장 저장공간 → Download → VoiceJson**입니다.

여러 녹음은 현재 목록 위치부터 아래로 진행합니다. 처음부터 하려면 삼성 목록 맨 위에서 시작합니다. 기존 전사가 없는 녹음은 건너뜁니다.

삼성 앱이 접근성 스크롤 명령을 거부하면 도우미는 현재 목록 영역 안에서 위로 스와이프합니다. 화면 좌표를 고정하지 않고 현재 목록의 위치와 크기를 읽어 스크롤합니다.

실행 중에는 화면 잠금을 풀어 둡니다. 중지하려면 알림의 **중지** 또는 앱의 **추출 중지**를 누릅니다. 다른 앱으로 이동하거나 화면을 잠그면 중지합니다. 인식하지 못하는 화면에서는 버튼을 추측하지 않고 최대 60초 후 중지합니다. 결과 화면에서 처리한 건수와 중지 이유를 확인합니다.

자동화를 사용하지 않을 때도 삼성 앱에서 **공유 → 텍스트 파일 → 전사 JSON 저장**을 선택해 파일을 저장할 수 있습니다.

동일한 원본 TXT는 해시로 구분해 기존 JSON을 재사용합니다. 수정된 TXT는 별도 JSON으로 저장합니다. 원본 TXT와 JSON 사본은 앱 내부에도 보관합니다.

## Drive 폴더에 올리기

1. 결과 화면에서 **Drive 폴더 선택**을 누릅니다. 저장함으로 들어가도 이 화면을 사용할 수 있습니다.
2. 시스템 파일 선택기의 왼쪽 메뉴에서 **Drive 계정**을 고릅니다. 저장할 폴더로 이동해 **이 폴더 사용**을 누릅니다. 에이전트의 Drive 연결에서도 접근 가능한 폴더를 선택합니다.
3. 결과 화면에 표시된 대상 폴더와 전사 수를 확인합니다. **선택한 폴더에 업로드**를 누릅니다.
4. 이 앱을 열어 둔 채 처리 결과를 확인합니다. 클라우드 동기화 상태는 Drive 앱에서 확인합니다.

전사 JSON과 함께 **llm.txt**, **index.json**을 저장합니다. llm.txt는 에이전트의 읽기 순서, 필드 의미, 인용 방법을 설명합니다. index.json은 파일 이름, 전사 제목, 발화 수와 원본 해시를 담습니다. 음성과 원본 TXT는 이 업로드에 포함되지 않습니다.

같은 내용은 재사용합니다. 앱이 이전에 쓴 파일을 사용자가 수정하지 않았을 때만 갱신합니다. 같은 이름의 다른 내용이나 원격 수정은 충돌로 중지합니다. 전용 폴더를 사용하면 기존 안내 파일과의 충돌을 피할 수 있습니다. 중단 후 다시 업로드하면 같은 파일은 재사용합니다. 파일 목록은 전사 파일을 모두 처리한 뒤 마지막에 갱신합니다.

에이전트에는 선택한 Drive 폴더를 알려주고 **llm.txt와 index.json부터 읽고 질문에 답해 달라**고 요청합니다. 이 앱에서 폴더를 선택했다고 에이전트의 Drive 계정에 접근 권한이 자동으로 추가되지는 않습니다.

출력 형식과 제한은 [FORMAT.md](FORMAT.md), 빌드 방법은 [BUILD.md](BUILD.md)를 확인합니다.
